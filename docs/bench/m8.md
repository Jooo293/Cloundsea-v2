# M8 基线记录：乘客视角（已移除）

> ⚠️ 该功能已在 M10 移除，本文仅作历史记录。移除原因见 [开发日志](../开发日志.md)。

> 目标：从云海切到车厢内部，窗外仍是同一片云海，车里有像素乘客。
> 日期：2026-11-17

## 1. 实现

| 部分 | 做法 |
| --- | --- |
| 车窗 | 不重算云海：每帧把主 WebGL 画布裁一块 `drawImage` 到车窗 canvas（`640×300`），按列车位移加视差 |
| 车厢 | 纯 CSS：穹顶 + 灯带 + 圆角车窗 + 两侧墙板 + 座椅 + 地板 |
| 乘客 | 三个程序化像素小人画在 `140×64` 的低分辨率 canvas 上，`image-rendering: pixelated` 放大 |
| 交互 | HUD「乘客视角」进入；点乘客 → 挥手 1.6 秒；「← 回到云海」或 `ESC` 退出 |
| 调试 | `?view=passenger` 直接进车厢截图 |

关键点：**窗外内容与主视图共享同一帧的画布**，所以时间轴、天气、主题、列车位移天然同步，不需要第二套渲染或状态同步。

代价是每帧一次 canvas→canvas 的裁剪贴图（仅在车厢视角下发生），成本远低于重画一遍。

## 2. 踩到的坑

- `#passenger-view` 同时有 HTML `hidden` 属性和 CSS `[hidden]{display:none}`，只加 `.show` 类不生效——`setOpen()` 必须同时切 `root.hidden`。
- 第一个版本乘客画布是 `240×80`，一行三个小人只占中间很小一块；改成 `140×64` 后放大约 1.7 倍才看得清。

## 3. 已知不足

| 项 | 说明 | 下一步 |
| --- | --- | --- |
| 车厢太"空" | 座椅只是一块渐变方块，没有靠背/窗框细节 | 加座椅靠背、行李架、扶手吊环 |
| 乘客只有 3 个姿势 | 坐姿 + 挥手，没有看书/打盹 | 用 sprite sheet 或状态机扩展 |
| 窗外没有窗框遮挡的层次 | 目前只是一块矩形裁剪 | 加窗框投影、玻璃反光条 |
| 移动端未适配 | 竖屏时车厢比例会怪 | 竖屏改上下分栏 |

## 4. 验收结论

- [x] HUD / ESC 进出车厢，DOM 与渲染都不崩
- [x] 窗外是实时主画面（同一帧裁剪），带列车位移视差
- [x] 三个像素乘客有呼吸式浮动，点击会挥手并出现对话小气泡
- [x] 无控制台报错
- [ ] 内饰与乘客动作需要美术迭代（见 §3）
- [ ] M9：打磨与发布（移动端、性能分级、单文件构建）
