# M6 基线记录：动态天气

> 目标：晴 / 阴 / 雷暴三态可切换，切换过程是 8 秒的参数插值，雷暴带闪电。
> 日期：2026-11-17

## 1. 设计：天气 = 一组命名参数

天气不新增场景，只改参数：

| 参数 | 晴 | 阴 | 雷暴 |
| --- | --- | --- | --- |
| 亮度 | 1.00 | 0.82 | 0.60 |
| 对比 | 1.00 | 0.96 | 1.14 |
| 饱和度 | 1.00 | 0.84 | 0.70 |
| 风速（云漂移倍率） | 1.0 | 1.35 | 1.9 |
| 粒子倍率 | 0.65 | 1.00 | 1.45 |
| 闪电频率 | 0 | 0 | 2.6 次/分 |

- **插值**：`smoothstep` 在 8 秒内把每个字段从旧值过渡到新值；
- **风速**：单独维护一条 `cloudTime` 累加器（`cloudTime += dt * wind`），云层漂移用它，UI 时间仍用 `elapsed`。风速回到 1 时 `cloudTime` 重新对齐 `elapsed`，不会跳变；
- **闪电**：泊松触发，包络是「前导微闪（0.07s）→ 主闪（指数衰减）→ 0.2s 后二次回闪」，由 final pass 叠一层冷白曝光。

`?weather=storm` 会**直接以该天气状态启动**（不做 8 秒过渡），方便截图；HUD 下拉切换则走过渡。

## 2. 回归验证

| 区域 | 结果 |
| --- | --- |
| 画布区域（排除标题与 HUD） | **平均差 0.0000，最大差 0** |
| 整图 | 0.77% 像素有差异——全部来自 HUD 多了一个「天气」下拉，布局变宽 |

晴天时 `uWeatherActive = 0`，着色器整段跳过，所以 classic 的画面逐像素不变。

## 3. 性能

| 场景 | 1080p 帧时 |
| --- | --- |
| cyber + 晴 | 8.36 ms |
| cyber + 雷暴 | 8.24 ms |

天气只是几个 uniform 与一个全屏加法，成本在测量噪声内。

## 4. 已知问题

| 问题 | 说明 | 下一步 |
| --- | --- | --- |
| 闪电只有"全屏闪白"，没有电弧 | 现在没有独立的闪电几何/纹理通道 | 用程序化分叉折线画在天空 pass，或预生成一张闪电 LUT |
| 雷暴的云没有额外变厚 | 只做了压暗与降饱和 | 雷暴时把 `disp` 放大 1.3 倍，或增加两层云 |
| 无雷声 | 音频模块还没接 | M9 与 BGM/音效一起做 |

> 雨丝方向已修：粒子函数加了 `uParticleDir`（+1 上升 / −1 下落），雷暴设 −1。
