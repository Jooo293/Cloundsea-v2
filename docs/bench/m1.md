# M1 基线记录：主题系统

> 目标：把云海从"shader 里写死 14 层"改成"数据驱动的 Theme"，并做到切换主题不重新编译 shader、不改变 classic 画面。
> 日期：2026-11-17

## 1. 做了什么

| 改动 | 说明 |
| --- | --- |
| 云层参数数据化 | `scene.glsl` 里 14 层云的 `midlevel/disp/dist/phase/色带高度/颜色` 全部移出，改为 `uLayer[16]`、`uBandDh[16]`、`uBandCount[16]` 三个 uniform 数组 |
| 调色板纹理 | 每层每条色带的 RGB 写进 128×1 的 `RGBA32F` 纹理，shader 用 `texelFetch` 精确取色（不用 8-bit，避免色偏） |
| 前景层同样数据化 | `uFgLayer[4]` + 独立调色板区（前 64 texel 给背景，后 64 给前景） |
| Theme 定义 | `src/themes/theme.js`：`classic` 逐条复刻原版数值（回归基线），`cyber/ink/polar` 用渐变 ramp 生成占位皮肤 |
| 热切换 | `renderer.setTheme(theme)` 只做 uniform 上传 + 一次 128×1 纹理上传，**不重建 program、不重载页面** |
| HUD | 新增「主题」下拉；URL 支持 `?theme=cyber|ink|polar|classic` |

代码位置：`src/themes/theme.js`、`src/scene/cloudsea.js#setTheme`、`src/shaders/scene.glsl`。

## 2. 回归验证：classic 必须和原版一模一样

做法同 M0：原版打补丁固定 `t=12.5`、关诗句，和新工程 `?freeze=1&t=12.5&theme=classic` 逐像素对比（取 UI 不覆盖的区域）。

| 指标 | 结果 |
| --- | --- |
| 差异 > 8 的像素 | **0.88%（全部是 1px 宽的抗锯齿描边）** |
| 3×3 邻域内全部超阈值的"实心块" | **0 个像素** |
| 差异分布 | 只沿云层边缘呈细线，无面状偏移 |

结论：**数据化重构没有改变任何一块画面**，只是把边缘像素落在哪一侧的判定从编译期常量换成了 uniform，导致个别边缘像素翻转。

对比图：`shots/theme-classic.png`（新）vs `shots/ref-t12.5.png`（原版）。

## 3. 性能（同一台机、同一条命令）

环境同 M0（headless Edge / ANGLE D3D11 / Intel Arc 核显 / `?bench=60&w=&h=` / `readPixels` 同步）。
每个分辨率跑 3 次，取中位数（单次波动约 ±1.5 ms，只看中位数）。

| 分辨率 | 三次测量（ms） | 中位数 | 60 fps 余量 |
| --- | --- | --- | --- |
| 1280×720 | 7.14 / 7.27 / 5.09 | **7.14** | +9.5 ms |
| 1600×900 | 7.19 / 9.35 / 9.47 | **9.35** | +7.3 ms |
| 1920×1080 | 11.54 / 11.81 / 11.68 | **11.68** | **+4.9 ms** |
| 2560×1440 | 16.50 / 18.47 / 18.93 | **18.47** | −1.9 ms |

补充：

- `cyber` 与 `classic` 的几何完全相同，实测 9.57 / 9.65 ms（1080p），与 classic 的 11.7 差在噪声范围内 → **改配色不带来额外开销**。
- 动态 `break` 的循环没有带来可见回退：1080p 中位数 11.68 ms，比 M0 单次测量的 14.23 ms 还低（M0 是单次采样，偏保守）。
- 1080p 仍有约 **4.9 ms** 余量，但要在 M2 加粒子 + bloom、M5 加域扭曲，**半分辨率云 pass 仍是必做项**。

## 4. 主题切换的代价

`setTheme()` 做的事：11 个 uniform 上传 + 1 次 128 texel 纹理上传。没有 program 编译、没有 DOM 重排，切换在同一帧内完成（实测切换后立即渲染无白屏）。

## 5. 已知限制（留给后续里程碑）

| 项 | 现状 | 计划 |
| --- | --- | --- |
| 列车/桥/烟配色 | 仍写死在 shader 里（深红车身、白烟） | M2 起改为 `uTrain*` 主题参数 |
| 三个新主题的观感 | 只是云层重新配色（占位） | M2 赛博朋克（粒子/城市/霓虹灯带 + bloom）、M3 水墨（积墨边缘/宣纸/远山）、M4 极地（冰晶/积雪/极光） |
| 天空 | 单色 `uSky`，无渐变/星点 | M2 换成竖直渐变 LUT |
| 天气 | 无 | M6 |

## 6. 验收结论

- [x] 主题纯数据配置，加主题不改 shader
- [x] 热切换无重编译、无白屏
- [x] classic 与原版逐像素等价（只有边缘 AA 差异）
- [x] 帧时未回退，1080p 余量 ≥ 4 ms
- [ ] M2：赛博朋克垂直切片（粒子 + 城市剪影 + 霓虹列车 + bloom）
