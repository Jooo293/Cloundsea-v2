# M9 基线记录：打磨与发布

> 目标：能发给别人玩——单文件、移动端可用、画质自适应、设置记得住。
> 日期：2026-11-17

## 1. 单文件构建

```powershell
cd cloudsea-v2
node tools/build-singlefile.mjs
# ✓ dist\cloudsea.html  5565 KB （模块 9 个，着色器 8 个）
```

做法（没有引入任何打包器）：

1. 内联 `<link rel=stylesheet>`；
2. 从 `src/main.js` 出发按 `import` 关系拓扑排序，去掉 `import` / `export` 关键字后顺序拼接；
3. 8 个着色器源文件读成对象，注入 `window.__SHADERS`；
4. `assets/noise.png` 转 data URL，注入 `window.__NOISE_URL`；
5. `loadText` / `loadImage` 优先读这两个全局，读不到才走 `fetch`（所以开发期照旧用 HTTP）。

**验证**：直接用 `file://` 打开 `dist/cloudsea.html?theme=cyber` —— 无控制台报错，画面与开发版逐像素一致（同参数渲染出的 PNG 字节数相同）。

体积构成：噪声图 4.0 MB（base64 后 5.5 MB）+ 代码约 80 KB。想再小可以把噪声图降到 512²（`fbm` 采样是 `p/1024`，需要同步改常量）。

## 2. 画质自适应

- 画质下拉新增「自动」并设为默认；
- 运行时按平滑帧时调节云层倍率：`avg > 20ms` 每帧降 0.05（下限 0.5），`avg < 11ms` 每帧升 0.02（上限 0.85）；
- 手动选「流畅/标准/高清」时固定倍率，不再自适应；
- `?cloudscale=` 可强制覆盖（调试用）。

## 3. 设置持久化

`localStorage["cloudsea-settings-v1"]` 存 `{ theme, weather, quality }`，下次打开自动恢复；URL 参数优先级更高（方便分享特定画面）。

## 4. 移动端

- `#stage { touch-action: none }`：长按蓄力时不会触发页面滚动/缩放；
- 720px 以下：HUD 换行、字号缩小、蓄力条上移、车厢视角的车窗与座椅改成窄屏比例；
- 430×860 竖屏实测可用（见 `shots/mobile.png`）。

已知：竖屏下 `uv.x` 范围只有 0.5，列车会占满大半个宽度，构图偏"近"。要真正适配竖屏需要给云层单独做一套纵向参数，留到后续。
