# M3 基线记录：国风水墨主题

> 目标：把 ink 从"灰一点的配色"做成一套可辨识的水墨语言：积墨边缘、飞白、宣纸、远山、仙鹤、木质车厢。
> 日期：2026-11-17

## 1. 本里程碑加了什么

| 元素 | 实现 | 位置 | 主题参数 |
| --- | --- | --- | --- |
| 去饱和调色 | 调色板换灰青渐变，饱和度大幅下降 | `themes/theme.js` | `ink.stops` |
| 积墨边缘 | 用 `dFdx/dFdy` 取亮度梯度 → `smoothstep` 成墨线 → 与低频噪声相乘做飞白 | `sky.frag` | `ink.edge / gain / color` |
| 宣纸 | 横向拉伸的纤维噪声 + 细颗粒，整体压暗 + 提亮 | `final.frag` | `paper` |
| 远山 | 低频 fbm + ridged fbm 生成山脊，画在**云之前**（云自然遮住山脚） | `sky.frag` | `mountains.on/near/far` |
| 仙鹤 | 振翅的 V 形 + 椭圆身体，两只不同相位缓慢横飞 | `composite.frag` | `cranes.on/color` |
| 木质车厢 | 车身上乘一层拉伸噪声，模拟木纹 | `composite.frag` | `train.grain` |

## 2. 回归验证

新元素全部由主题参数门控（`ink.edge=0`、`paper=0`、`mountains.on=0`、`cranes.on=0`、`train.grain=0`）。

| 指标 | 结果 |
| --- | --- |
| classic 改动前后 | **平均差 0.0000，最大差 0** |

即 M3 对 classic 完全无影响，像素级完全一致。

## 3. 性能

| 主题 | 1080p 帧时 |
| --- | --- |
| cyber（M2b） | 8.88 ms |
| ink（M3） | **8.94 ms** |

积墨边缘（一次梯度 + 一次 fbm）、远山（两次 fbm）、仙鹤（两个循环）加起来不到 0.1 ms——它们都跑在半分辨率的天空 pass 或全分辨率但很廉价的合成 pass 上。

## 4. 诚实评价：哪里还不够"水墨"

| 问题 | 原因 | 下一步 |
| --- | --- | --- |
| 墨线偏"碎点" | 直接在 1px 尺度上对颜色求梯度，再乘低频飞白，线条容易断成斑点 | 先对天空图做一次小半径模糊，再在模糊图上取梯度；或沿梯度方向做 9-tap 洇染（计划里预留过） |
| 远山与云难以区分 | 两者都是中灰，且远山被云遮得太多 | 拉开明度差（山更浅、云更暗），或让山脊只在云顶之上出现 |
| 仙鹤造型简陋 | 只是 V 形 + 身体，没有腿/颈/尾 | 换成 2D 剪影 sprite（一笔画路径），或程序化画颈与腿 |
| 木纹很淡 | `grain` 只在车身上调制亮度 | 增加沿车身方向的拉伸 + 接缝高光线 |

这些都属于"美术迭代"，不是架构问题；M3 的验收标准（功能齐全、classic 不受影响、帧时可控）已经达到。

## 5. 验收结论

- [x] 水墨主题具备：去饱和配色、积墨边缘、飞白、宣纸、远山、仙鹤、木纹车厢
- [x] classic 像素级不变（最大差 0）
- [x] 1080p 帧时 8.94 ms，仍在预算内
- [ ] 墨线质感与仙鹤造型需要美术迭代（见 §4）
- [ ] M4：极地（冰晶云 / 积雪列车 / 天空极光）
