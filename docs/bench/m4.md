# M4 基线记录：极地冰雪主题

> 目标：把 polar 从"冷一点的配色"做成一套冰雪语言：极光、冰晶棱线、积雪列车、冷白调色。
> 日期：2026-11-17

## 1. 本里程碑加了什么

| 元素 | 实现 | 位置 | 主题参数 |
| --- | --- | --- | --- |
| 极光 | 3 条上下摆动的光带（`sin` + `fbm` 位移），竖向流苏用 fbm 调制，画在云海之上、只保留画面上部 | `sky.frag` | `aurora.on/strength/color` |
| 冰晶 | Voronoi 边界（F2−F1）当晶体棱线，用亮度阈值只在亮的云面上出现，叠一点时间闪烁 | `sky.frag` | `ice.on/strength/scale/color` |
| 积雪 | 车顶与车厢上沿按高度渐变 + 噪声打碎边缘，跟着 mask 走 | `composite.frag` | `train.snow` |
| 冷白调色 | 蓝→青→白的渐变，最亮端压到 `#e6f5ff`，避免过曝 | `themes/theme.js` | `polar.stops` |
| 雪粒 | 复用粒子系统（白色、低速、低密度） | `composite.frag` | `particles.*` |

极光没有用原版 Shadertoy 的体积 ray march：一是成本（50 步 × 每像素）与当前 4.5 ms 的余量不匹配，二是原版是 CC BY-NC-SA（仅非商业）。现在这套是"三条光带 + 噪声流苏"的近似，观感够用且几乎免费。

## 2. 回归验证

| 指标 | 结果 |
| --- | --- |
| classic 改动前后 | **平均差 0.0000，最大差 0** |

极光/冰晶/积雪全部由主题参数门控，classic 完全不受影响。

## 3. 性能

| 主题 | 1080p 帧时 |
| --- | --- |
| cyber（M2b） | 8.88 ms |
| ink（M3） | 8.94 ms |
| polar（M4） | **10.39 ms** |

Voronoi（9 邻域）+ 三条极光带带来约 1.5 ms 的增量，仍在 16.6 ms 预算内（余量 6.2 ms）。

## 4. 调过的地方（记录参数取舍）

| 参数 | 初值 | 结果 | 终值 |
| --- | --- | --- | --- |
| `ice.strength` | 0.55 | 整个云海像裂开的冰壳，边缘全是粗白线 | 0.18（并用亮度做遮罩） |
| `ice` 边缘宽度 | `smoothstep(0.015, 0.09)` | 线太粗 | `smoothstep(0.0, 0.035)` |
| `post.bloom` | 0.45 | 高光过曝，云全白 | 0.25 |
| 极光位置 | 云之后（会被完全挡住） | 看不见 | 云之上 + 只保留上部 45% |
| 极光颜色 | `#62ffbf` | 叠加后发白 | `#22d98a`、强度 0.7 |

## 5. 已知问题

| 问题 | 说明 | 下一步 |
| --- | --- | --- |
| 极光偏"青带" | 叠在亮云上会被冲淡，绿色不纯 | 用加法混合前先压暗云顶，或改用柔光/滤色混合 |
| 冰晶在低分辨率下变糊 | 棱线宽度接近半分辨率的一个像素 | 冰晶改到全分辨率的 composite pass，或提高对比 |
| 积雪在浅色车身上不明显 | 车身 `#8fa6bb` 与雪只差一点 | 车身再压暗一档，或给雪加蓝色阴影边 |
