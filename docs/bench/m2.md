# M2 基线记录：赛博霓虹垂直切片

> 目标：在不破坏 classic 回归基线的前提下，把「赛博朋克」从配色占位做成完整的一版：夜空、星点、城市剪影、银灰列车 + 霓虹灯带、粒子、扫描线。
> 日期：2026-11-17

## 1. 本里程碑加了什么

| 元素 | 实现方式 | 主题参数 |
| --- | --- | --- |
| 渐变夜空 | `mix(skyBottom, skyTop, uv.y)`，经典主题两端同色 → 等价常量 | `sky.top / sky.bottom` |
| 星点 | 屏幕空间 240×240 网格哈希，亚像素圆点 + 闪烁 | `sky.stars`（0 关闭） |
| 列车材质 | 车身 / 车顶 / 饰条三个颜色 uniform，替换原版写死的 `vec3` | `train.body/roof/trim` |
| 霓虹灯带 | 车厢下沿 `y∈[0.103,0.109]` 叠 emissive，外加 `exp(-Δy·55)` 光晕与车头径向光 | `train.emissive/energy` |
| 城市剪影 | 3 层视差（14/22/34 列），楼高按列哈希、留空 18%，窗光细分 4 列 | `city.on/color/window` |
| 粒子 | 屏幕空间网格 + 上滚，雪花/尘埃两种用法 | `particles.color/density/speed` |
| 扫描线 | `fract(fragCoord.y*0.5)` 暗条 | `post.scanline` |
| 指针视差 | 星点 / 城市 / 粒子按深度偏移，云层速度不变 | 运行时 `uParallax` |
| 烟的柔化 | `mix(col, smoke, strength)`，经典主题 strength=1 保持原样 | `train.smokeStrength` |

> 没有上真正的 bloom 链：霓虹的"发光"是解析光晕（指数衰减）做出来的。真实 bloom 与云 pass 半分辨率放到 M2b，理由是 1080p 只剩约 4 ms，先把预算留给后续里程碑。

## 2. 回归验证：classic 必须逐像素不变

新增元素全部由主题参数门控（`stars=0`、`city.on=0`、`particles.density=0`、`energy=0`、`scanline=0`、`smokeStrength=1`），因此 classic 输出应与 M1 完全一致。

| 指标 | 结果 |
| --- | --- |
| 平均绝对误差 | **0.0000** |
| 最大通道误差 | **1 / 255** |
| 差异 > 8 的像素 | **0.00%** |

结论：M2 的所有新特性都是"主题驱动"的，不污染基准画面。

## 3. 性能

环境同前（headless Edge / ANGLE D3D11 / Intel Arc 核显 / 60 帧 / `readPixels` 同步）。

| 主题 | 1080p 帧时 | 说明 |
| --- | --- | --- |
| classic | 12.09 ms | 与 M1 的 11.68 ms 相当（噪声范围内） |
| cyber | 9.47 / 9.69 ms | 城市 + 粒子 + 星点均为程序化小函数，成本低于云层噪声的波动 |

- 1080p 仍在 16.6 ms 预算内（余量约 4–5 ms）。
- 城市/粒子/星点的成本可以忽略：一次哈希查询 + 几个 `step`，远低于一层 8 octave 的 fbm。
- 结论保持：**真正吃预算的仍是 14 层 8 octave 的云**，M2b 的半分辨率要针对它，而不是针对新元素。

## 4. 视觉决策与已知问题

| 项 | 现状 | 后续 |
| --- | --- | --- |
| 城市位置 | 屏幕空间固定基线（y≈0.34–0.42），不随云层起伏 | M5 云层可变形后，把天际线锚到云顶高度 |
| 城市观感 | 纯黑剪影 + 青窗光，块面偏硬 | M2b 加边缘光与远景雾化 |
| 烟 | 赛博主题降到 55% 混合，仍偏"实体" | 后续改成半透明贴片或体积雾 |
| 霓虹 | 解析光晕，无 bloom | M2b 上真正的 bloom 链 |
| 列车 | 银灰 + 青色灯带，轮廓仍是原版的侧视剪影 | M2b 加受电弓/车窗灯带细节 |
| 极光/冰晶/水墨笔触 | 未做 | M3 / M4 |

## 5. 验收结论

- [x] 赛博霓虹主题在 1080p 可跑、可截图、无控制台报错
- [x] classic 逐像素不变（最大差 1/255）
- [x] 主题切换仍不需要重编译 shader
- [x] 1080p 帧时仍在预算内
- [ ] M2b：bloom 链 + 云 pass 半分辨率（为 M3 之后的功能腾预算）
