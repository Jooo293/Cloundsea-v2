# M7 基线记录：列车操控与飞行

> 目标：长按蓄力 → 脱轨 → 云海自由飞行 → 自动回轨；列车离开轨道时云层被拨开、桥淡出。
> 日期：2026-11-17

## 1. 状态机

```text
rail --长按--> charging --松手(蓄力≥15%)--> flying --靠近轨道 / 停手 10s--> docking --> rail
                      \--松手(蓄力<15%)--> rail（取消）
```

- 蓄力 1.1 秒到满，初速 `vy = 0.30 + 0.55×power`、`vx = 0.12 + 0.18×power`（uv 单位/秒）；
- 飞行中：重力 0.55、阻尼 `exp(-1.15·dt)`、指针牵引（弹簧增益 1.7）；
- 位置钳制在 `x∈[-0.2, aspect-0.62]`、`y∈[-0.18, 0.52]`，保证列车不会飞出画面；
- 停手 1.2 秒视为"无输入"，累计 10 秒自动进入 `docking`，0.3 秒左右滑回轨道。

## 2. 渲染侧的配合

| 机制 | 实现 |
| --- | --- |
| 列车位移 | `composite.frag` 里 `tuv = (uv - center - uTrainOffset)/uTrainScale + center`，再走原来的 mask |
| 飞行放大 | `uTrainScale` 从 1 平滑到 1.5，让离开轨道后仍可辨认 |
| 桥淡出 | `uRailFade` 作为桥的不透明度（1 → 0.45）；**注意公式**：`mix(col, bridge, (1-keep) * fade)`，写成 `1-(1-k)*fade` 会几乎看不出效果（犯过这个错） |
| 烟淡出 | 飞行时 `uSmokeFade` 降到 0.15，避免烟停在半空 |
| 拨云跟随 | `setCarve(0.225 + offset.x, 0.315 + offset.y, 0.13)`，每帧跟着列车 |

## 3. 交互与 HUD

- 画布任意处长按开始蓄力，底部出现蓄力条（0–100%）；
- 松开起飞；飞行中移动指针引导方向；
- 底部提示文案随状态切换：轨道 → 蓄力中 → 飞行中 → 回轨中；
- 调试参数：`?train=0.10,0.16`（直接停在飞行姿态）、`?charge=0.65`（停在蓄力状态）。

## 4. 性能

1080p / 云倍率 0.75 / 赛博霓虹：**8.26 ms**（与 M6 持平）。列车物理是纯 JS 标量运算，成本可忽略；位移只是多两个 uniform。

## 5. 诚实评价：飞行的列车看起来像"一道光"

离开桥之后，列车只剩 6–20 px 高的一条：车体灰蓝色在暗紫夜空里几乎看不见，只剩下霓虹灯带和车头光，读起来像"一道划过天空的光带"。

这不是 bug，是原版美术的局限——列车本来就是侧视剪影，靠桥的栏杆和云带勾勒出轮廓。要真正好看需要：

1. **飞行姿态**：抬轮、车身倾斜（现在只做了整体位移与放大，没有旋转）；
2. **轮廓光**：飞行时给车体加一圈冷色 rim light；
3. **尾迹**：拖一条发光粒子/蒸汽尾迹，把"在飞"这件事说清楚。

这些放进 M8 之后的美术打磨，不影响 M7 的功能验收。
